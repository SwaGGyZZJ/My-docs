口径：分数按每题 checklist 的满分归一到 10 分。“模型步骤”是回答阶段的 model call 数。“实际读 Wiki”要求有页面正文返回。回答耗时和 token 只统计最终回答尝试；评分耗时只统计评分器最终尝试。生成、失败重试及评分 token 不包含在简表的回答成本中。输入、输出、推理和缓存读取分别记录，不应直接相加为计费 token。仅代码仓组只有 62/122 题保留完整回答重试明细，因此不能与其他组比较完整重试成本。

本表从本地逐题答案和评分记录重新计算，并与冻结的六组共同题汇总核对；公开目录仅提供组级汇总。
