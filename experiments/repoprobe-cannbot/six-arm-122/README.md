相对仅代码仓基线的变化，以及回答 prompt 的核心差异：

| 组别 | 得分较基线 | 平均每题回答总 Token 较基线已记录值 | Prompt 差异 |
|---|---:|---:|---|
| 仅代码仓 | 0.00% | 基线（仅已知下界） | 通用 prompt；源码权威；不提 Wiki |
| 代码仓 + 强制 OpenWiki | +4.86% | ≤+93.29% | 强制先读 `quickstart.md` 和另一 Wiki 页，再用源码核验 |
| 代码仓 + 可选 OpenWiki | +4.10% | ≤+23.75% | 明确告知 Wiki 可用；Agent 自行决定是否读取 |
| 仅 OpenWiki | −36.93% | ≤−15.20% | 仅 Wiki 可用；强制读两页；禁止读取源码 |
| 代码仓 + `/init` AGENTS.md | −1.98% | ≤+110.68% | 强制先读根 `AGENTS.md`；禁止读取 OpenWiki |
| 代码仓 + 静默可见 OpenWiki | −0.46% | ≤+15.71% | 回答 prompt 与基线完全相同；仅工作区额外可见 Wiki |

得分差异 =（该组均分 ÷ 基线均分 − 1）×100%。Token 差异 =（该组平均每题回答总 Token ÷ 基线已记录的平均每题回答总 Token − 1）×100%。六组题数相同，因此用每题均值与组级合计计算的百分比一致。因基线 60 题缺少回答尝试明细，分母可能偏小，所以 `≤` 表示实际百分比不高于表中的数值，不能据此断言精确成本差异。

数值完整、可筛选的版本是 [CSV](repoprobe-six-arm-122-summary.csv)。要直接复制到 Excel，请打开 [TSV](repoprobe-six-arm-122-summary.tsv) 的 **Raw** 页面，复制全部内容后粘贴到单元格 A1。六组工作区、完整回答 prompt、生成 prompt 和评分 prompt 见 [流程和提示词](PROMPTS_AND_COST.md)。

口径：分数按每题官方 checklist 的满分归一到 10 分。“模型步骤”是回答阶段的 model call 数。“实际读 Wiki”要求有页面正文返回。首表回答耗时及分项 token 仍只统计最终回答尝试；第二表每题回答 token 包含全部已知回答重试，每题评分 token 包含全部评分重试。“总 tokens”是模型 trace 的 `tokens.total`，等于 input + output + reasoning + cache.read；这是 token 用量，不是货币账单。每题均值是 122 题总量除以 122。组级合计保留在 CSV/TSV 中用于对账。OpenWiki 与 `/init` 的仓库级共享生成成本单列，未强行归属到单题。仅代码仓组只有 62/122 题保留完整回答重试明细，第二表的该组为下界。

本表从本地逐题答案和评分记录重新计算，并与冻结的六组共同题汇总核对；公开目录仅提供组级汇总。
